# 🔐 Générateur de mot de passe

Un script Bash simple pour generer un mot de passe. Le script demande les spécificités du mot de passe (avec/sans caractères speciaux, avec/sans numéro)

## 🚀 Generer un mot de passe

chmod +x password.sh
```

Then, generate a password by specifying the desired length. For example, to generate a password containing 12 characters, run:

```bash
./password.sh 12
```

### Exemple de sortie 

```text
aZ7@kL2!mP9x
```

## ⚙️ Requirements

- Linux
- Bash
